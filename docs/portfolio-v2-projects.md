# Portfolio v2 — Blueprint da Seção de Projetos

## Objetivo

A seção de Projetos representa o principal elemento técnico do portfólio.

Seu objetivo não é apenas listar aplicações desenvolvidas, mas demonstrar capacidade de projetar, documentar, desenvolver, testar e entregar software de qualidade.

Cada projeto deve ser apresentado como um estudo de caso, permitindo que recrutadores e desenvolvedores compreendam rapidamente o problema resolvido, a arquitetura utilizada, as decisões técnicas adotadas e o resultado final.

---

# Filosofia

O portfólio não deve funcionar como uma galeria de imagens.

Também não deve funcionar como uma simples lista de tecnologias.

Cada projeto deve contar uma história.

O visitante deve compreender:

- qual problema foi resolvido;
- como a solução foi construída;
- quais tecnologias foram utilizadas;
- quais decisões técnicas foram tomadas;
- qual foi o resultado obtido.

As tecnologias são consequência da solução, nunca o foco principal.

---

# Objetivos da nova seção

A nova seção deverá:

- transmitir profissionalismo;
- valorizar projetos reais;
- priorizar evidências visuais;
- apresentar arquitetura de software;
- destacar decisões técnicas;
- facilitar leitura rápida;
- permanecer escalável para futuros projetos.

---

# Princípios

## 1. Nunca utilizar placeholders quando existirem imagens reais.

As capturas reais do sistema sempre terão prioridade.

---

## 2. Todo projeto deverá possuir um estudo de caso.

Mesmo projetos menores deverão possuir uma página dedicada.

---

## 3. Toda imagem deverá possuir contexto.

Nenhuma imagem deve existir apenas por estética.

Cada captura deverá possuir:

- título;
- descrição curta;
- objetivo da tela.

---

## 4. Estrutura consistente.

Todos os projetos deverão seguir exatamente a mesma estrutura.

Isso permitirá crescimento futuro sem necessidade de redesign.

---

## 5. Escalabilidade

A seção deverá suportar naturalmente:

- 2 projetos;
- 5 projetos;
- 10 projetos;
- mais projetos futuramente.

Não deverá existir qualquer estrutura fixa baseada na quantidade atual de projetos.

---

# Estrutura da Home

A seção de projetos deverá apresentar todos os projetos utilizando o mesmo padrão visual.

Cada card deverá conter:

- imagem principal;
- nome do projeto;
- descrição resumida;
- stack principal;
- links para estudo de caso;
- GitHub;
- deploy (quando disponível).

Todos os cards deverão possuir exatamente a mesma hierarquia visual.

A importância de um projeto será percebida pela qualidade do conteúdo e não pelo tamanho do card.

# Considerações Finais

Este documento define o padrão oficial da seção de Projetos do Portfolio v2.

Todo novo projeto deverá seguir estas diretrizes para manter consistência visual, técnica e de experiência do usuário.

A evolução do portfólio deverá ocorrer através da melhoria do conteúdo apresentado e não através de alterações constantes na identidade visual.
